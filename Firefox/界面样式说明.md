下面以 Firefox 130 源码为准。

**一、界面装配结构**

```text
browser.xhtml
├─ main-popupset.inc.xhtml           右键菜单、弹出面板
├─ appmenu-viewcache.inc.xhtml       主菜单内容
├─ navigator-toolbox.inc.xhtml       标签栏、导航栏、书签栏
├─ browser-box.inc.xhtml             侧边栏和网页内容
└─ fullscreen-and-pointerlock...     全屏相关组件
```

主入口是 [browser.xhtml](/E:/moz/firefox-130.0.1/browser/base/content/browser.xhtml:35)。其中 `#include` 会在构建时把 `.inc.xhtml` 合并进去，不是运行时 iframe。

`<body>` 默认使用 XUL 命名空间，因此：

- `<toolbarbutton>`、`<toolbar>`、`<hbox>` 是 XUL 组件。
- `<html:img>`、`<html:input>` 是普通 HTML 组件。
- `flex="1"` 是 Firefox/XUL 布局属性。

**二、常见组件位置**

| 组件 | 结构定义 | 主要样式 |
|---|---|---|
| 标签栏 | [navigator-toolbox.inc.xhtml](/E:/moz/firefox-130.0.1/browser/base/content/navigator-toolbox.inc.xhtml:24) | `tabbrowser/tabs.css` |
| 导航栏 | 同文件第 124 行 | `browser-shared.css`、`toolbarbuttons.css` |
| 地址栏 | 同文件第 178 行 | `urlbar-searchbar.css`、`identity-block.css` |
| 窗口按钮 | [titlebar-items.inc.xhtml](/E:/moz/firefox-130.0.1/browser/base/content/titlebar-items.inc.xhtml:5) | `windows/browser.css` |
| 书签栏 | `navigator-toolbox.inc.xhtml` 第 528 行 | `browser-shared.css`、Places 样式 |
| 网页和侧边栏 | [browser-box.inc.xhtml](/E:/moz/firefox-130.0.1/browser/base/content/browser-box.inc.xhtml:5) | `sidebar.css`、内容区样式 |
| 应用菜单 | `appmenu-viewcache.inc.xhtml` | `customizableui/panelUI.css` |

**三、样式加载顺序**

[浏览器窗口](/E:/moz/firefox-130.0.1/browser/base/content/browser.xhtml:50) 加载 `chrome://browser/skin/`，Windows 下解析为 [windows/browser.css](/E:/moz/firefox-130.0.1/browser/themes/windows/browser.css:5)，然后导入 [browser-shared.css](/E:/moz/firefox-130.0.1/browser/themes/shared/browser-shared.css:1)。

选择文件原则：

- 所有平台共用：`browser/themes/shared/`
- 仅 Windows：`browser/themes/windows/`
- 标签页：`shared/tabbrowser/tabs.css`
- 通用按钮尺寸和状态：`shared/toolbarbuttons.css`
- 按钮图标：`shared/toolbarbutton-icons.css`
- 地址栏：`shared/urlbar-searchbar.css`

Firefox 样式大量依赖状态属性：

```css
:root[sizemode="maximized"] { }
:root[uidensity="compact"] { }
:root[lwtheme] { }
:root[inFullscreen] { }
#nav-bar[customizing] { }
toolbarbutton:is([open], [checked]) { }
```

尺寸、颜色应优先定义 CSS 变量，避免在多个选择器重复硬编码。

**四、添加普通可定制按钮**

独立按钮更适合加入 [CustomizableWidgets.sys.mjs](/E:/moz/firefox-130.0.1/browser/components/customizableui/CustomizableWidgets.sys.mjs:453)：

```js
{
  id: "yun-settings-button",
  l10nId: "toolbar-button-yun-settings",
  onCommand(event) {
    event.view.openTrustedLinkIn("about:preferences", "tab");
  },
},
```

然后把 ID 加入 [CustomizableUI.sys.mjs](/E:/moz/firefox-130.0.1/browser/components/customizableui/CustomizableUI.sys.mjs:245) 的默认导航栏顺序：

```js
let navbarPlacements = [
  "back-button",
  "forward-button",
  "stop-reload-button",
  "spring",
  "urlbar-container",
  "spring",
  "yun-settings-button",
  "downloads-button",
];
```

用户布局保存在 `browser.uiCustomization.state`。修改默认顺序只对新配置或“恢复默认工具栏”生效；升级已有用户时，需要修改 `kVersion` 并添加布局迁移逻辑。

**五、添加复合组件**

地址栏、组合按钮等复杂结构应直接写入 `navigator-toolbox.inc.xhtml`：

```xml
<toolbaritem id="yun-toolbar-item"
             class="chromeclass-toolbar-additional"
             removable="true">
  <toolbarbutton id="yun-main-button"
                 class="toolbarbutton-1"
                 data-l10n-id="toolbar-button-yun"
                 oncommand="YunToolbar.onCommand(event);"/>
  <label id="yun-status-label"/>
</toolbaritem>
```

需要多个窗口共享状态时，把业务逻辑放入 `.sys.mjs`；只操作当前窗口时，可以使用浏览器窗口脚本。应优先监听 `command`，不要只监听 `click`，否则键盘操作可能失效。

可复用命令定义在 [browser-sets.inc](/E:/moz/firefox-130.0.1/browser/base/content/browser-sets.inc:60)，实际分发在 [browser-sets.js](/E:/moz/firefox-130.0.1/browser/base/content/browser-sets.js:128)。

**六、定义按钮样式和图标**

```css
#yun-settings-button {
  list-style-image: url("chrome://browser/skin/yun-settings.svg");
}

#yun-settings-button[checked] {
  fill: AccentColor;
}

#yun-toolbar-item {
  margin-inline: 4px;
}
```

保留 `toolbarbutton-1`，即可继承按钮大小、悬停、按下、紧凑模式和高对比度样式。

SVG 推荐使用 Firefox 的主题着色格式：

```xml
<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 16 16"
     fill="context-fill"
     fill-opacity="context-fill-opacity">
  <path d="..."/>
</svg>
```

参考 [back.svg](/E:/moz/firefox-130.0.1/browser/themes/shared/icons/back.svg:4)。新增资源还必须登记到 [jar.inc.mn](/E:/moz/firefox-130.0.1/browser/themes/shared/jar.inc.mn:147)，否则 `chrome://browser/skin/...` 无法加载。

**七、本地化**

组件中只写 Fluent ID：

```xml
data-l10n-id="toolbar-button-yun-settings"
```

在 `browser/locales/en-US/browser/browser.ftl` 添加：

```properties
toolbar-button-yun-settings =
    .label = Yun settings
    .tooltiptext = Open Yun settings
```

中文需要同步到对应的 `zh-CN` 本地化仓库。不要在 XHTML 中直接硬编码中文。

**八、调试和构建流程**

1. 使用 Browser Toolbox 检查浏览器自身 DOM，而不是普通网页开发者工具。
2. 在 Style Editor 临时修改 CSS，确认效果后再写回源码。
3. CSS/XHTML 修改通常执行：

```bash
E:\moz\start-shell130.bat dbg
./mach build faster
./mach run
./mach lint -l stylelint browser/themes/shared/browser-shared.css
```

4. 新增 `jar.mn` 资源或修改脚本打包后，如果 `build faster` 未更新，执行完整 `./mach build`。

测试至少覆盖普通、最大化、全屏、窄窗口、工具栏自定义、紧凑模式、深色主题和高对比度。当前工作区未因本次教程产生修改。

## 样式属性

Firefox 130 的浏览器界面主要使用 XUL 组件。它们看起来类似 HTML，但默认布局、属性和事件机制不同。基础规则位于 [xul.css](/E:/moz/firefox-130.0.1/toolkit/content/xul.css:18)：XUL 元素默认是 `display:flex` 和 `box-sizing:border-box`。

**通用属性**

| 属性 | 作用 |
|---|---|
| `id` | CSS、JavaScript、命令和本地化的唯一定位标识 |
| `class` | 应用通用样式，如 `toolbarbutton-1`、`subviewbutton` |
| `flex="1"` | 占用剩余空间；数字越大，分配空间的权重越高 |
| `align="center"` | 交叉轴对齐，类似 `align-items:center` |
| `pack="center"` | 主轴对齐，类似 `justify-content:center` |
| `orient="horizontal"` | 明确排列方向；`hbox` 默认横向，`vbox` 默认纵向 |
| `hidden="true"` | `display:none`，销毁对应布局 frame |
| `collapsed="true"` | `visibility:collapse`，隐藏但保留 frame |
| `persist="width height"` | 跨启动保存指定属性 |
| `context="menu-id"` | 绑定右键菜单 |
| `tooltip="tooltip-id"` | 使用指定的 tooltip 节点 |
| `tooltiptext="..."` | 直接设置提示文字，不建议硬编码 |
| `role`、`aria-*` | 无障碍语义和状态 |
| `data-l10n-id` | Fluent 本地化键 |
| `data-l10n-args` | Fluent 动态参数 |
| `data-l10n-attrs` | 指定需要本地化的属性 |

`hidden` 和 `collapsed` 的底层定义见 [xul.css](/E:/moz/firefox-130.0.1/toolkit/content/xul.css:24)。

**布局组件**

`toolbox` 是多行工具栏容器，默认纵向排列。当前 `navigator-toolbox` 包含标题栏、导航栏和书签栏。

`hbox` 默认横向排列：

```xml
<hbox flex="1" align="center" pack="start">
  ...
</hbox>
```

`vbox` 默认纵向排列：

```xml
<vbox flex="1" align="stretch">
  ...
</vbox>
```

在 CSS 中可以直接覆盖：

```css
#my-container {
  flex: 1;
  min-width: 0;
  gap: 8px;
  align-items: center;
}
```

弹性容器中的可缩放子项通常需要 `min-width:0`，否则长文本或地址栏可能无法缩小。

**toolbar 属性**

导航栏示例位于 [navigator-toolbox.inc.xhtml](/E:/moz/firefox-130.0.1/browser/base/content/navigator-toolbox.inc.xhtml:124)。

| 属性 | 说明 |
|---|---|
| `customizable="true"` | 允许进入“自定义工具栏”模式 |
| `customizationtarget="..."` | 指定实际接收可定制按钮的子容器 |
| `mode="icons"` | 只显示图标；还支持 `text` 等模式 |
| `fullscreentoolbar="true"` | 参与全屏工具栏显示/隐藏 |
| `overflowable="true"` | 空间不足时允许项目进入溢出面板 |
| `default-overflowbutton` | 溢出按钮 ID |
| `default-overflowtarget` | 普通组件溢出目标 |
| `addon-webext-overflowtarget` | 扩展按钮溢出目标 |
| `context` | 工具栏右键菜单 |
| `nowindowdrag` | 禁止把工具栏空白部分作为窗口拖动区 |

工具栏默认具有 `-moz-window-dragging:drag`；按钮、输入框、标签页会自动设置为 `no-drag`，见 [xul.css](/E:/moz/firefox-130.0.1/toolkit/content/xul.css:307)。

**toolbarbutton 属性**

```xml
<toolbarbutton id="yun-button"
               class="toolbarbutton-1 chromeclass-toolbar-additional"
               data-l10n-id="toolbar-button-yun"
               command="Yun:Open"
               removable="true"
               overflows="true"/>
```

主要属性：

- `command`：引用 `<command id="...">`，同时继承其 `disabled` 状态。
- `oncommand`：直接执行操作，支持鼠标和键盘。
- `onclick`：底层鼠标事件；不要用它替代主要命令。
- `key`：关联 `<key>` 快捷键，也可用于动态 tooltip。
- `disabled="true"`：禁用按钮。
- `checked="true"`：复选或切换按钮已选中。
- `type="checkbox"`：自动维护选中语义。
- `type="menu"`：点击打开内部 `menupopup`。
- `type="menu-button"`：主按钮和下拉按钮组合。
- `removable="false"`：用户不能从工具栏移除。
- `overflows="false"`：空间不足时也不能进入溢出面板。
- `badged="true"`：启用角标结构。
- `closemenu="none"`：点击后不关闭所在菜单。
- `crop="end"`：文字过长时截断尾部。
- `delegatesanchor`、`consumeanchor`：面板锚点传递，主要供 PanelUI 使用。
- `keepbroadcastattributeswhencustomizing`：自定义模式下继续同步命令属性。

顶部按钮应使用 `toolbarbutton-1`；应用菜单按钮使用 `subviewbutton`。基础尺寸见 [toolbarbuttons.css](/E:/moz/firefox-130.0.1/browser/themes/shared/toolbarbuttons.css:59)。

**toolbaritem、spring 和 spacer**

`toolbaritem` 用于包装地址栏、组合按钮等复杂组件，自身不会生成标准按钮外观。

`toolbarspring` 是可变空白：

```css
toolbarspring {
  flex: 1;
  min-width: 28px;
  max-width: 112px;
}
```

`toolbarspacer` 是普通固定空白。需要稳定间距时更适合 CSS `gap`、`margin-inline` 或限制后的 spring，不应依赖无限扩张的 spring。

`skipintoolbarset="true"` 表示组件不加入工具栏持久化顺序，适用于提示文字、装饰元素等内部节点。

**tab 和 tabs 属性**

标签页容器位于 [navigator-toolbox.inc.xhtml](/E:/moz/firefox-130.0.1/browser/base/content/navigator-toolbox.inc.xhtml:49)。其状态主要由 `tabbrowser.js` 动态设置：

- `selected`：当前逻辑选中的标签。
- `visuallyselected`：视觉上已选中。
- `multiselected`：多选标签之一。
- `pinned`：固定标签页。
- `busy`：页面正在加载。
- `pending`：标签尚未恢复。
- `fadein`：标签已进入正常显示生命周期。
- `soundplaying`：正在播放声音。
- `muted`：静音。
- `attention`：需要用户注意。
- `image`：存在 favicon。
- `overflow`：标签数量超出可用宽度。
- `orient="vertical"`：垂直标签模式。

样式不要手动修改这些属性，应根据属性写状态选择器，参考 [tabs.css](/E:/moz/firefox-130.0.1/browser/themes/shared/tabbrowser/tabs.css:584)。

**菜单和面板**

`menupopup` 是传统菜单，通常作为 `menu` 或 `toolbarbutton type="menu"` 的子元素。

`panelview` 是 PanelMultiView 中的一页：

```xml
<panelview id="yun-main-view" class="PanelUI-subView">
  <vbox class="panel-subview-body">
    <toolbarbutton class="subviewbutton"/>
  </vbox>
</panelview>
```

- `subviewbutton`：标准菜单行。
- `subviewbutton-nav`：显示进入下一级页面的箭头。
- `subviewbutton-iconic`：显示图标。
- `closemenu="none"`：操作后保持面板打开。
- `ViewShowing`、`ViewHiding`：面板页显示和隐藏事件。

参考 [appmenu-viewcache.inc.xhtml](/E:/moz/firefox-130.0.1/browser/base/content/appmenu-viewcache.inc.xhtml:5)。

**样式定义机制**

推荐按“变量、基础状态、特殊状态、平台状态”的顺序组织：

```css
:root {
  --yun-button-size: 32px;
  --yun-button-gap: 8px;
}

#yun-button {
  width: var(--yun-button-size);
  list-style-image: url("chrome://browser/skin/yun.svg");
}

#yun-button:is([open], [checked]) {
  background-color: var(--toolbarbutton-active-background);
}

:root[uidensity="compact"] #yun-button {
  --yun-button-size: 28px;
}

@media (-moz-platform: windows) {
  :root[sizemode="maximized"] #yun-button {
    margin-block-start: 0;
  }
}
```

优先复用 Firefox 主题变量，例如：

- `--toolbar-bgcolor`
- `--toolbar-color`
- `--toolbarbutton-icon-fill`
- `--toolbarbutton-hover-background`
- `--toolbarbutton-active-background`
- `--button-hover-bgcolor`
- `--urlbar-min-height`
- `--tab-min-height`

这样可以自动兼容深色主题、轻量主题、高对比度和不同 UI 密度。不要直接写死大面积背景色、按钮高度或图标颜色。

最后需要注意：XHTML 属性通常是初始状态，运行后 JavaScript 会动态增加、删除或修改属性。设计样式时应在 Browser Toolbox 中观察真实运行时 DOM，而不能只看源码中的初始属性。
