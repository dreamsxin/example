结论：`FB_LOG_INFO` 没有独立的 FB 日志开关，它使用 Firefox 自带的 `MOZ_LOG` 框架，日志模块名是 `dxlog`。

**开启方式**

在 MozillaBuild Shell 中运行：

```bash
export MOZ_LOG='dxlog:4,timestamp,sync'
export MOZ_LOG_FILE='E:/moz/logs/moz-%PID'
cd /e/moz/firefox-130.0.1
./mach run -- -no-remote -profile E:/moz/profiles/test
```

PowerShell：

```powershell
New-Item -ItemType Directory -Force E:\moz\logs | Out-Null

$env:MOZ_LOG = "dxlog:4,timestamp,sync"
$env:MOZ_LOG_FILE = "E:\moz\logs\moz-%PID"

cd E:\moz\firefox-130.0.1
.\mach run -- -no-remote -profile E:\moz\profiles\test
```

写入 `start-shell130.bat` 时，可以放在调用 `start-shell.bat` 之前：

```bat
@echo off
set "MOZBUILD_STATE_PATH=E:\moz\.mozbuild130"
set "MOZ_LOG=dxlog:4,timestamp,sync"
set "MOZ_LOG_FILE=E:\moz\logs\moz-%PID"

call C:\mozilla-build\start-shell.bat
```

Firefox 会自动生成类似文件：

```text
moz-main.12340.moz_log
moz-child.23456.moz_log
```

`%PID` 很重要，否则多个内容进程可能争用同一个日志文件。

日志等级：

| 配置 | 输出范围 |
|---|---|
| `dxlog:3` | `FB_LOG_INFO` |
| `dxlog:4` | `FB_LOG_INFO` 和 Debug |
| `dxlog:5` | 全部 dxlog 日志 |

建议使用 `dxlog:4`，因为当前 `FB_LOG_WARNING` 实际使用的是 `LogLevel::Debug`，而不是真正的 `Warning`。这是一个命名与等级不一致的问题，后续可以改成：

```cpp
mozilla::LogLevel::Warning
```
