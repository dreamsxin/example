## 打开

先打开普通网页，然后按以下步骤启用浏览器控制台：

1. 地址栏输入：

```text
about:config
```

2. 搜索并设置：

```text
devtools.chrome.enabled = true
devtools.debugger.remote-enabled = true
```

3. 使用快捷键打开“浏览器控制台”：

```text
Ctrl + Shift + J
```

也可以通过菜单打开：

```text
右上角菜单 → 更多工具 → 浏览器工具箱 → 浏览器控制台
```

注意区分：

- `F12` 或 `Ctrl + Shift + K`：网页控制台，作用于当前网页。
- `Ctrl + Shift + J`：浏览器控制台，可访问浏览器窗口、`Services` 和工具栏 DOM。

打开后，可输入：

```js
const w = Services.wm.getMostRecentWindow("navigator:browser");
```

检查工具栏节点：

```js
w.document.getElementById("XX-toolbar-info");
```

查看当前显示值：

```js
({
  environment: w..camouGetToolbarEnvironmentInfo(),
  proxy: w..camouGetToolbarProxyInfo(),
  custom: w..camouGetToolbarCustomInfo(),
});
```

强制更新工具栏：

```js
w.FbToolbarInfo.update();
```

若控制台出现“多行模式”，按 `Ctrl + Enter` 执行代码。

```js
(() => {
  .camouSetToolbarEnvironmentInfo("001 / 测试");
  .camouSetToolbarProxyInfo("HTTP代理 / 192.168.1.100:8080");
  .camouSetToolbarCustomInfo("自定义测试信息");

  const result = {
    environment: .camouGetToolbarEnvironmentInfo(),
    proxy: .camouGetToolbarProxyInfo(),
    custom: .camouGetToolbarCustomInfo(),
  };

  console.table(result);
  return result;
})();
```
