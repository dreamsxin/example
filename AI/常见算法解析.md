# 常见算法解析

## 1. K-近邻算法（K-Nearest Neighbors, KNN）

**白话理解**  
你想知道一个新朋友喜欢什么运动，就去问他最相似的 K 个朋友喜欢什么，投票决定。不看全局，只看最近邻居。

**核心数学**  
给定测试点 \(x\)，在训练集 \(\mathcal{D} = \{(x_i, y_i)\}\) 中找到距离最近的 \(K\) 个点 \(\mathcal{N}_K(x)\)，然后多数投票：

\[
\hat{y} = \arg\max_{c} \sum_{i \in \mathcal{N}_K(x)} \mathbb{I}(y_i = c)
\]

距离通常用欧氏距离：
\[
d(x, x_i) = \sqrt{\sum_{j=1}^d (x^{(j)} - x_i^{(j)})^2}
\]

**关键点**  
- 不需要训练，属于惰性学习。
- K 值选择很关键：太小过拟合，太大欠拟合。
- 距离度量敏感，需要特征缩放（标准化）。
- 在高维空间中，距离概念退化（维度灾难）。

**适用场景**  
小数据集、低维特征、分类问题，推荐系统初版。

## 2. 线性回归

**白话理解**  
找一条直线（或超平面）尽可能穿过所有数据点。新数据来了直接代公式就能预测数值。

**核心数学**  
假设模型：\( \hat{y} = w^T x + b \)。通过最小化均方误差求解参数：

\[
\mathcal{L}(w, b) = \frac{1}{n} \sum_{i=1}^n (y_i - (w^T x_i + b))^2
\]

解析解（最小二乘法）：
\[
w = (X^T X)^{-1} X^T y
\]
其中 \(X\) 是加了全 1 列偏置项的设计矩阵。

梯度下降更新规则：
\[
w := w - \eta \nabla_w \mathcal{L}, \quad b := b - \eta \frac{\partial \mathcal{L}}{\partial b}
\]

**关键点**  
- 假设线性关系、误差独立同分布、方差齐性。
- 解析解需要 \(X^T X\) 可逆，大规模数据用梯度下降。
- 容易欠拟合，需特征工程添加多项式项或交互特征。

**适用场景**  
房价预测、销量预测等连续值回归，要求解释性强。

---

## 3. 逻辑回归

**白话理解**  
虽然叫回归，但做分类。把线性结果套进 Sigmoid 函数，压成 0 到 1 的概率。大于 0.5 就判正类。

**核心数学**  
对二分类，预测样本 \(x\) 为正类的概率：
\[
p(y=1|x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}}
\]

损失函数（交叉熵）：
\[
\mathcal{L} = -\frac{1}{n} \sum_{i=1}^n [y_i \log p_i + (1-y_i) \log(1-p_i)]
\]

梯度更新与线性回归形式相同，但 \(p_i\) 非线性的。

**关键点**  
- 输出有概率意义，可校准。
- 决策边界是线性的，但可通过特征变换处理非线性。
- 可扩展到多分类（Softmax 回归）。
- L1/L2 正则化可防过拟合，L1 还能做特征选择。

**适用场景**  
二分类基线模型，信用评估、疾病初筛、广告点击率预估。

## 4. 决策树

**白话理解**  
像玩“20 个问题”游戏，根据特征值逐层提问，直到把数据分到足够纯的叶子节点。

**核心数学**  
构建树的过程是递归选择最优特征划分。常用纯度度量：
- 分类树：基尼系数 \( Gini = 1 - \sum_k p_k^2 \) 或 信息熵 \( H = -\sum_k p_k \log_2 p_k \)
- 回归树：均方误差 \( MSE = \frac{1}{|D|} \sum_{i \in D} (y_i - \bar{y})^2 \)

选择划分特征 \(j\) 和分割点 \(s\) 最小化加权不纯度：
\[
\min_{j,s} \left[ \frac{|D_{\text{left}}|}{|D|} \text{Imp}(D_{\text{left}}) + \frac{|D_{\text{right}}|}{|D|} \text{Imp}(D_{\text{right}}) \right]
\]

**关键点**  
- 可解释性强，能处理非线性关系。
- 容易过拟合，需要剪枝（预剪枝/后剪枝）或限制深度。
- 对微小数据变化敏感，不稳定。
- 连续特征找分割点，多叉或二叉。

**适用场景**  
需解释性的分类/回归，如医疗诊断、客户分群。

## 5. 随机森林

**白话理解**  
种一片树，每棵树只看部分数据、部分特征，最终投票或取平均。群体决策比单棵树稳。

**核心数学**  
随机森林 = Bagging + 随机子空间。对 \(B\) 棵树：
- 每棵树从原始数据集 \(D\) 中自助采样（bootstrap）得到 \(D_b\)。
- 每个节点分裂时，从全部 \(d\) 个特征中随机选 \(m \ll d\) 个候选特征。

分类投票：
\[
\hat{y} = \arg\max_c \sum_{b=1}^B \mathbb{I}(h_b(x) = c)
\]
回归取平均：
\[
\hat{y} = \frac{1}{B} \sum_{b=1}^B h_b(x)
\]

**关键点**  
- 显著降低方差，消除单棵树的过拟合。
- 可输出特征重要性：基于袋外误差（OOB）或平均不纯度减少。
- 并行训练，效率高。
- 失去单棵树的可解释性。

**适用场景**  
工业界分类回归主力，特征维度高、样本量适中即可。

## 6. 朴素贝叶斯

**白话理解**  
根据贝叶斯公式算每个类别的概率，假设特征之间独立。简单到有时离谱，但计算飞快。

**核心数学**  
对给定样本 \(x = (x_1, ..., x_d)\)，求后验概率：
\[
p(y=c|x) \propto p(y=c) \prod_{j=1}^d p(x_j | y=c)
\]
预测类别：
\[
\hat{y} = \arg\max_c p(y=c) \prod_{j=1}^d p(x_j | y=c)
\]
其中先验 \(p(y=c)\) 和条件概率 \(p(x_j|y=c)\) 从训练集统计得到：
- 特征离散：计数+平滑（拉普拉斯平滑）
- 特征连续：假设高斯分布 \(p(x_j|y=c) = \mathcal{N}(\mu_{jc}, \sigma_{jc}^2)\)

**关键点**  
- “朴素”即特征条件独立假设，现实中常不成立，但往往效果还能接受。
- 训练速度快，内存小，适合在线学习。
- 对缺失数据不敏感。
- 概率估计常不准（因为独立假设过强），但分类决策可能仍正确。

**适用场景**  
文本分类（垃圾邮件过滤）、实时预测，基线模型。

## 7. 支持向量机（SVM）

**白话理解**  
在两类数据之间画一条“街道”，让街道最宽。只靠站在街边的那几个点（支持向量）来决定边界。

**核心数学**  
目标是找到超平面 \(w^T x + b = 0\)，最大化间隔 \(\frac{2}{\|w\|}\)，即最小化 \(\frac{1}{2} \|w\|^2\)，且正确分类所有点（硬间隔）：
\[
\min_{w,b} \frac{1}{2} \|w\|^2 \quad \text{s.t.} \quad y_i(w^T x_i + b) \ge 1, \forall i
\]

软间隔引入松弛变量 \(\xi_i\) 允许少量错误：
\[
\min_{w,b,\xi} \frac{1}{2} \|w\|^2 + C \sum_i \xi_i, \quad \text{s.t.} \; y_i(w^T x_i + b) \ge 1 - \xi_i, \xi_i \ge 0
\]

对偶形式使用核技巧 \(K(x_i, x_j) = \phi(x_i)^T \phi(x_j)\)，将数据映射到高维空间实现非线性分割。常见核：线性、多项式、RBF。

**关键点**  
- 决策边界仅由支持向量决定，内存高效。
- 核技巧隐式映射，避免显式高维计算。
- 对特征缩放敏感，需要标准化。
- 大规模数据训练慢，时间复杂度 \(O(n^2) \sim O(n^3)\)。

**适用场景**  
中小规模数据，文本分类、图像识别、生物信息学。

## 8. Boosting (以 AdaBoost 和梯度提升为例)

**白话理解**  
一群人挨个考试，后一个人专门做前面人做错的题，反复迭代，最后综合所有人的意见，准确率大幅提升。

**核心数学 - AdaBoost**  
初始化样本权重 \(w_i^{(1)} = 1/n\)。对于 \(t=1..T\)：
1. 用权重分布训练弱分类器 \(h_t\)。
2. 计算加权错误率：
   \[
   \epsilon_t = \sum_{i: h_t(x_i) \neq y_i} w_i^{(t)}
   \]
3. 计算分类器权重：
   \[
   \alpha_t = \frac{1}{2} \ln \frac{1 - \epsilon_t}{\epsilon_t}
   \]
4. 更新样本权重，错分样本增重：
   \[
   w_i^{(t+1)} \propto w_i^{(t)} \exp(-\alpha_t y_i h_t(x_i))
   \]
最终强分类器：
\[
H(x) = \text{sign}\left(\sum_{t=1}^T \alpha_t h_t(x)\right)
\]

**核心数学 - 梯度提升 (GBDT)**  
每一轮拟合当前模型的负梯度（伪残差）：
\[
r_{i}^{(t)} = - \left[ \frac{\partial L(y_i, F(x_i))}{\partial F(x_i)} \right]_{F = F_{t-1}}
\]
新学习器 \(h_t(x)\) 拟合 \(r^{(t)}\)，通过线搜索求步长 \(\rho_t\)，更新：
\[
F_t(x) = F_{t-1}(x) + \nu \cdot \rho_t h_t(x)
\]
其中 \(\nu\) 是学习率（shrinkage）。

XGBoost/LightGBM 进一步引入二阶导数近似和正则化项。

**关键点**  
- 串行训练，偏差逐步降低，容易过拟合（需控制学习率、树深度、早停）。
- 对异常值敏感。
- 梯度提升通常比随机森林准确率高，但调参较复杂。
- XGBoost/LightGBM/CatBoost 是工程化实现，效率高。

**适用场景**  
结构化数据分类回归竞赛主力，表格数据几乎万能。

---

以上八个算法涵盖了分类、回归、集成学习，理解它们的数学本质和适用边界，就构成了机器学习面试的算法基础底座。
