##

### 🎨 综合与2D美术资源

- https://kenney.nl/assets
独立开发圈的“招牌站”，提供风格高度统一的2D精灵、3D模型、UI套件和音效，几乎全部为CC0协议，可免费商用且无需署名，是快速搭建原型的最佳起点。

- https://opengameart.org/
老牌的开源游戏素材“大仓库”，汇集了全球开发者上传的2D/3D美术、音乐和音效。素材量极大，但质量参差不齐，且每个素材的授权协议不同（从CC0到需署名都有），下载前务必逐一确认。

- https://itch.io/game-assets/free
独立游戏平台Itch.io的素材区，可按“免费”筛选。这里有很多个人艺术家上传的风格化素材包，从图标、精灵图到Tileset都有，适合寻找独特、非主流的美术风格。

- https://craftpix.net/freebies/
提供高质量的免费2D素材，以精美的角色精灵、游戏背景、GUI套件和图标见长。站点同时提供付费资源，免费区是很好的“试吃”入口。

- https://www.gameart2d.com/freebies.html
专门提供免费的2D游戏角色和场景素材，适合需要现成角色立绘或场景图的2D项目。

- https://game-icons.net/
一个拥有超过4000个免费SVG/PNG图标的宝库，覆盖技能、武器、道具、UI等各类需求。图标风格统一且实用，采用CC BY 3.0协议，使用时需要署名原作者。

### 🧊 3D模型与动画

- https://polyhaven.com/
提供高质量的CC0协议3D资产库，主打HDRIs（高动态范围环境贴图）、PBR材质和逼真的3D模型，适合对画面质感有较高要求的3D项目。

- https://quaternius.com/
专注于提供CC0协议的低多边形（Low-poly）3D模型包，涵盖角色、环境、道具和动画，风格统一且模块化，非常适合独立游戏。

- https://sketchfab.com/features/free-3d-models
大型3D模型平台Sketchfab的免费专区，模型种类极其丰富，但授权协议因模型而异，下载前需仔细查看。

- https://www.mixamo.com/
Adobe提供的免费人物模型和动画资源库，尤其适合需要人形角色骨骼动画（如走路、奔跑、攻击）的项目，注册后即可下载使用。

- https://free3d.com/
提供各类免费3D模型的网站，可作为寻找特定模型的补充渠道。

### 🎵 音效与音乐

- https://freesound.org/
目前最大的开源音效社区之一，拥有超过40万个音效和采样素材，种类极其丰富。授权协议混合（CC0, CC-BY等），商用前需查看具体要求。

- https://opengameart.org/art-search-advanced?field_art_type_tid%5B%5D=13
OpenGameArt的音效专用筛选页面，可以直接在这里浏览和筛选开源游戏音效。

- https://sound-effects.bbcrewind.co.uk/
BBC提供的音效库，包含大量高质量的广播级音效，适合需要特定环境音或专业音效的项目。

- https://soundimage.org/
提供免费的音乐、音效和图片素材，适合寻找游戏背景音乐（BGM）的开发者。

- https://www.zapsplat.com/
提供免费音效和音乐，可作为音效资源的补充来源。

### 🛠️ 辅助工具与调色板

- https://lospec.com/palette-list
像素画创作者的“调色板图书馆”，收录了数百套现成的像素画配色方案，可直接导出为多种格式，能有效解决像素画的配色难题。

- https://assetstore.unity.com/
Unity官方资源商店，其中“Top Free”分类下有大量可直接导入Unity项目的免费模型、纹理、动画和完整项目示例。

- https://www.fab.com/
Epic Games推出的数字资产平台，整合了原Quixel、Sketchfab等资源，会限时提供免费的3D资产，需要留意免费截止日期。
